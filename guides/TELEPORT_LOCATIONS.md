# Teleport Location Coordinates

This guide contains all available teleport locations with their coordinates for use with the Royal Seed Pod or other teleportation methods.

## How to Use

### With Royal Seed Pod (Pnda Only)
1. Get the Royal Seed Pod: `::item 19564`
2. Click "Teleport" on the item
3. Enter the X coordinate when prompted
4. Enter the Y coordinate when prompted
5. Enter the height (0-3, usually 0 for ground level)

### With Commands (Admin Only)
- Use `::tele X Y` or specific commands like `::varrock`, `::edge`, etc.

## Quick Command Reference (Admin Only)

- `::home` - Teleport to home location
- `::varrock` - Teleport to Varrock (3211, 3424)
- `::lumbridge` - Teleport to Lumbridge (3222, 3217)
- `::falador` - Teleport to Falador (2966, 3379)
- `::edge` - Teleport to Edgeville (3087, 3499)
- `::yanille` - Teleport to Yanille (2606, 3093)
- `::gnome` - Teleport to Gnome Stronghold (2461, 3443)
- `::thieving` - Teleport to Thieving test area (2591, 4731)

## Coordinate System Notes

- **X**: East-West coordinate (increases going East)
- **Y**: North-South coordinate (increases going North) - Called Z in some RS systems
- **Height**: Vertical plane (0 = ground level, 1 = first floor, 2 = second floor, 3 = third floor)
- **Valid Range**: X and Y must be between 0 and 16383
- **Height Range**: 0-3
